# 8AM 経済インテリジェンス

倉光さん専用の「自分を教育するニュース」。直近24時間の国内外の経済・ビジネスニュースから、知っておくべき「5つの変化」を選び、背景と今後の見通しまで解説する。さらに、製薬企業向けのプロジェクトマネージャーとして押さえておくべき業界ニュースを「PHARMA DESK」として加える。

## 読者プロフィール（解説の⑤はここに引きつけて書く）

- 本業：医療スタートアップで、製薬企業と疾患領域別のマーケティング施策を企画・推進するPM。医師向けの専門医相談サービスや、医師向けAIを扱う
- 副業：Upworkで、日本市場への参入・拡大を検討する海外のヘルスケア・製薬・メドテック企業向けのアドバイザーとして、スポット案件を受ける準備中
- 関心：予防医療、希少疾患・難病、「誰も取り残さない医療」、医療AI
- 個人資産：金利・為替・株・不動産の変化が家計にどう効くかを知りたい
- 好み：池上彰さんのように噛み砕いた説明。専門用語には一言で説明を添える

## 構成

### メイン：5つの変化
- THE BIG ONE（最重要の変化）／BUSINESS（企業・経営への影響）／NEXT（AI・テクノロジー・メディアなどの未来）／MONEY（金利・為替・株・債券・不動産・インフレ・税制と個人資産）／WILD CARD（視野を広げる、意外だが重要なテーマ）
- 記事5本の要約ではなく、複数の情報を束ねて構造的な変化を取り出す
- 各テーマで ①何が起きたか ②なぜ重要か ③背景にある構造変化 ④今後のシナリオと二次・三次の波及 ⑤倉光さんの仕事・キャリア・個人資産への影響
- 重要テーマでは、市場の一般的な解釈だけでなく、反対シナリオと「こうなったら見立てが外れる」という条件も示す

### PHARMA DESK：製薬企業向けPMとして押さえておきたい3本
- 対象：日本の薬価・制度（中医協、薬価収載、費用対効果評価、中間年改定）、承認・部会審議、製薬企業の発売・提携・導入、MRや医師への情報提供のあり方の変化、医療DX・医療AI、希少疾患・難病の新薬、海外の規制で日本に波及するもの
- 各項目で「何が起きたか」「PMとしての意味（製薬企業のマーケティングや疾患領域別の施策にどう効くか）」「会話のネタ（クライアントとの雑談や提案で使える切り口）」を書く。必要に応じて反対シナリオも
- 新薬の収載・承認は、疾患領域と「医師がどう患者に気づくか」の観点を添える
- 未確認の情報は「報じられた」「詳細は未確認」と明記する
