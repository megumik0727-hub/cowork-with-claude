# 8AM 経済インテリジェンス

倉光さん専用の「自分を教育するニュース」。直近24時間の国内外の経済・ビジネスニュースから、知っておくべき「5つの変化」を選び、背景と今後の見通しまで解説する。

## 設定（元ネタのプロンプトを要約）

- 記事5本の要約ではなく、複数の情報を束ねて構造的な変化を取り出す
- ラインナップ：THE BIG ONE（最重要の変化）／BUSINESS（企業・経営への影響）／NEXT（AI・テクノロジー・メディアなどの未来）／MONEY（金利・為替・株・債券・不動産・インフレ・税制と個人資産）／WILD CARD（視野を広げる、意外だが重要なテーマ）
- 各テーマで ①何が起きたか ②なぜ重要か ③背景にある構造変化 ④今後のシナリオと二次・三次の波及 ⑤倉光さんの仕事・キャリア・個人資産への影響
- 重要テーマでは、市場の一般的な解釈だけでなく、反対シナリオと「こうなったら見立てが外れる」という条件も示す
- 池上彰さんのように噛み砕いて書く
- 過去に扱ったテーマとつなげ、継続して観測する（下の表を毎回更新）
