# LINEスタンプ制作フロー

倉光さんと2026年10月に「ゆるクマおじさん構文」スタンプ（4パターン×24枚）を作ったときの手順と学びをまとめたもの。成果物の実例は `line-emoji/kuma/`（`records.tsv`、`README.md`、`_grid_*.png`）にある。

## 0. 先に押さえる前提

- **スタンプと絵文字は別物**。絵文字は180×180px、1セット8〜40個で、文章中に並べて使う。通常のスタンプは下の規格。ユーザーが「一文字ずつ打つのはだるい」と言ったら、スタンプが向いている。
- **呼びかけに名前を入れない**。「〇〇チャン」は全員に合わないので「キミ」などの汎用的な呼称にする。
- 方向性は試作を見せながら何度も変わる前提で進める。実際の流れは、腰長絵文字 → ひらがな絵文字 → かわいいおじさん → 吹き出し → 顔文字だけ → 書体違い → ゆるキャラ、と変わった。各段階で、数枚の試作と一覧画像を見せて判断してもらう。

## 1. 企画

1. コンセプト、ターゲット、セリフの方向性を聞く。サンプル画像はスクリーンショットで届くことが多い。
2. セリフのリストを作る。ユーザーからもらう場合はそのまま使い、名前の部分は「キミ」に置き換えたことを伝える。
3. 枚数は **8・16・24・32・40** のどれか。20枚は作れないので、早めに伝える。足す場合は、既存のパターンで手薄な場面（おやすみ、天気、お祝い、寝坊など）を選ぶ。

## 2. キャラクターの原画（Canva）

- `mcp__Canva__generate-image` を、正方形（`SQUARE_1_1`）で使う。
- 2案を並べて比べてもらう（例：くまとうさぎ）。左右対称を明示しないと、耳が片方しかない、髪型が左右非対称などの「AIっぽい」崩れが出る。
- 倉光さんが気に入った絵柄は、2頭身、おなかぽっこり、線だけで描いたタレ目、線少なめ、フラットな色、白背景。
- 既存のキャラクター（参考画像、カカオやLINEのキャラクター）に寄せすぎない。雰囲気だけ取り入れて、オリジナルにする。
- 決まった原画の media id を控える（くまは `MAHXBGNiB4c`）。

## 3. スタンプの生成（Canva）

原画を `imageReferences` に渡し、次のテンプレートでプロンプトを作る。

```
LINE sticker using the exact same bear character as the reference (same ultra-simple doodle style,
few thin wobbly lines, flat colors, 2-head-tall, pot belly, droopy line eyes, tiny round glasses,
small mustache, one hair on top, no clothes). Pose: {セリフに合うポーズ}.
Japanese hand-written style text in dark brown, render exactly: "{セリフ}".
Draw any emoji in the text as small simple doodle icons in the same style.
Text arranged in 2-3 lines around the character, readable.
White background, generous margins, no other text anywhere in the image.
```

- 日本語のセリフは、Canvaでかなり正確に描ける。末尾の絵文字は、省かれるか小さなアイコンになることが多い。
- 「no other text anywhere」を入れないと、小物に「ポテチ」「ENERGY」「既読 12:34」などの余計な文字が入る。
- **生成回数の上限（quota_cooldown）**：最初は8〜10枚を同時に投げられるが、使ううちに数分で1枚程度まで落ちる。失敗したら `sleep` をバックグラウンドで回して待ち、1〜2枚ずつ投げる。
- 結果は `get-generate-image-job` で回収する。受け取れるのは200pxの縮小画像だけなので、誤字の最終確認はCanvaのリンクでしてもらう。

## 4. 記録と一覧

- 生成するたびに `records.tsv` へ1行追記する（`pattern  no  text  media_id  blob`）。blob は縮小画像のファイル名末尾の6文字。
- `scripts/grid.py` を作業フォルダにコピーし、パターン名と出力名の対応（`keys`）を合わせて実行する。パターンごとの一覧画像 `_grid_*.png` と縮小画像ができる。
- 一覧画像は `SendUserFile` で送る。Canvaのリンク一覧は `README.md` にまとめる。
- 縮小画像で、ポーズ違い、余計な文字、変な形（手のハートが耳に見えるなど）を確認し、作り直し候補として伝える。
- こまめにコミットしてプッシュする。stop hook が未コミットの変更を止めるため。

## 5. 申請用の書き出し（ガイドライン）

公式 https://creator.line.me/ja/guideline/sticker/ はこの環境からは開けない。ユーザーのスクリーンショットで確認済みの内容は次のとおり。

| 画像 | 必要数 | サイズ | 容量 |
|---|---|---|---|
| メイン画像 | 1 | 240×240px | 1MB以下 |
| スタンプ画像 | 8/16/24/32/40 | 最大370×320px | 1個1MB以下 |
| トークルームタブ画像 | 1 | 96×74px | 1MB以下 |

- PNG、背景透過、72dpi以上、RGB、縦横は偶数ピクセル。
- 画像の外枠と絵の間に **10pxぐらいの余白** が必要。
- ZIPでまとめてアップロードする場合は60MB以下。審査をリクエストしたあとは、個数を変更できない。
- 手順：Canvaの `remove-background` で背景を消す → 余白10px以上を取って、370×320以内の偶数サイズに配置する → `scripts/check_specs.py <フォルダ>` で、サイズ、透過、余白、四隅の消し残し、個数、容量を確認する。黒背景に重ねて、目でも消し残しを確認する。
- Canvaでの配置：`create-design` で作業用デザインを作り（1264×1264の白紙が1ページできる）、`read-design`（open_transaction）→ `edit-design` の `add_page`（page_index=1）で370×320を個数分、240×240、96×74を足す。いったんcommitしてから開き直してページIDを取り、`insert_fill` でスタンプを300×300・(35,10)、メインを220×220・(10,10)、タブを70×70・(13,2)に置き、commitする。
- ZIP：export-download.canva.com はこの環境から取得できない。ユーザーにCanvaの「共有 → ダウンロード → PNG・背景透過・2ページ目以降」でダウンロードしてもらう。受け取ったzipを `scripts/package.py <zip> <出力zip>` に通すと、画像サイズで振り分けて 01〜NN.png、main.png、tab.png に名前を付け直す。展開して `check_specs.py` を通してから返す。「透過なし(RGB)」になったページは、Canvaでレイヤー分解されて背景が白い画像になっていることが多い。`scripts/clear_white_bg.py <png>` で白を透過にし、暗い背景に重ねて目で確認する（文字の内側の白、細い隙間の白っぽさ）。

### NGなスタンプ（審査で見られる点）

- 日常会話で使いにくいもの（物体、景色だけなど）
- 視認性が悪いもの（横長、8頭身の全身、長すぎるセリフ）。トーク画面の大きさ（約半分）で読めるか確かめる。
- 淡い色ばかり、単なる数字の羅列など、全体のバランスを欠くもの
- 公序良俗に反するもの、未成年の飲酒・喫煙を想起させるもの、性的表現、暴力的表現、ナショナリズムを煽るもの。おじさん構文の「ナンチャッテ」は、セクハラのごまかしとして紹介されることがあるので、性的なほのめかしは入れない。
- 宣伝目的のもの（発売日の告知、企業ロゴだけ）、LINE以外のサービス名やそのキャラクター名、購入者に個人情報やIDを求めるもの
- AIで作った画像そのものは、禁止事項として書かれていない（2026年10月時点、解説記事ベース）。申請時にAI利用の有無を聞かれたら正直に答える。Canvaの画像を商用利用してよいかは、本人に規約を確認してもらう。

### 申請テキスト（全角は2文字として数える。絵文字は使えない）

- タイトル40文字以内、クリエイター名50文字以内、説明文160文字以内、コピーライトは英数字のみ50文字以内。
- 文字数は `unicodedata.east_asian_width` で、W・F・Aを2文字として数えて確認する。

## 6. プログラムで作る場合（Canvaを使わない）

文字だけのスタンプや、つなげて使う絵文字なら、Pillowで規格どおりに描ける（`line-emoji/make_kobun2.py`、`make_emoji.py`）。

- 書体は npm の `@fontsource/*` から取得する。GitHubへの直接アクセスは403になる。大きな日本語書体は文字ごとにファイルが分かれているので、fontTools で文字と書体ファイルの対応表を作って使う。
- 絵文字は `/usr/share/fonts/truetype/noto/NotoColorEmoji.ttf`（OFL）を size=109、`embedded_color=True` で描いてから縮小する。iPhoneの絵文字の絵柄は使えない。
- ただし、手描きプログラムのキャラクターは「AI感・素人感」が出やすい。絵柄はCanvaに任せる方が評価が高かった。
