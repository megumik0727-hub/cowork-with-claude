# ⑤ 購入特典（有料部分の最後に掲載）

## 特典1：4つのmdファイル テンプレート

### CLAUDE.md
```
# 【仕事の名前】のルール

## 最初にやること
- knowledge.md / references.md / learn.md を読む

## 手順
1. 材料（【ファイル名】）を読む
2. references.md のお手本と同じ形式で作る
3. 【必ず入れる項目】を入れる
4. 「【保存するファイル名】」として保存する

## 守ること
- わからない箇所は推測せず【要確認】と書く
- 固有名詞は knowledge.md の表記に合わせる
- 指摘を受けたら learn.md に1行で追記する

## やらないこと
- 材料にない数字や事実を書く
- 【その他の禁止事項】
```

### knowledge.md
```
# 知識・決まりごと

## 用語・略語
- 【略語】＝【正式名称】

## 人・取引先の表記
- 【名前】（【部署・役割】）

## 会社・チームの決まりごと
- 【例：金額は税込で書く】
```

### references.md
```
# お手本

## 【仕事の名前】_お手本1
（ここに過去のいちばん良い成果物を貼る）
```

### learn.md
```
# 修正履歴

| 日付 | 指摘 | 今後のルール |
|---|---|---|
| 【日付】 | 【何がダメだったか】 | 【次からどうするか】 |
```

## 特典2：任せる仕事チェックシート

| 仕事 | 繰り返し | 型がある | 材料がある | 確認できる | 合計 |
|---|---|---|---|---|---|
| 例：議事録 | ○ | ○ | ○ | ○ | 4 |
| | | | | | |
| | | | | | |

→ **4つとも○の仕事から任せる。** 3つなら2番目に。2つ以下はまだ任せない。

## 特典3：定型業務プロンプト10本

1. **議事録**：「会議メモ_◯◯.txt から議事録を作って。決定事項・宿題（担当・期限）・次回日程に分けて、CLAUDE.md のルールで保存して」
2. **メール返信**：「このメールへの返信を3案作って。丁寧／簡潔／断る場合。knowledge.md の取引先の呼び方に合わせて」
3. **要約**：「この資料を、忙しい上司が1分で読める形にまとめて。結論3行→理由→判断してほしいこと の順で」
4. **集計**：「売上.csv を取引先別・月別に集計して表にして。前月比が±20%を超えた取引先に印をつけて」
5. **突き合わせ**：「請求書一覧と入金一覧を突き合わせて、金額が合わないもの・入金がないものを一覧にして」
6. **社内通知**：「この内容を社内通知にして。いつ・誰が・何をするか を最初に書いて、300字以内で」
7. **マニュアル化**：「この作業メモを、新人が読んでも迷わない手順書にして。画面の操作は番号付きで」
8. **週報**：「今週の作業ログから週報を作って。できたこと・できなかったこと・来週やること の3つで」
9. **比較表**：「この3つの案を、費用・手間・効果・リスクで比べた表を作って。最後におすすめを1つ」
10. **ダメ出しの記録**：「今の指摘を learn.md に追記して。次から同じミスをしないルールの形で書いて」
