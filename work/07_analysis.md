# ⑦ 売上データ分析（手順）

販売開始後、週1回この手順で分析して、次の商品や投稿に反映します。

## 毎日記録すること（スマホで送ってOK）
- noteの販売数・PV（noteの「ダッシュボード」から）
- Threadsの投稿ごとの表示数・いいね・返信（インサイトから）
→ Claudeに送れば `07_sales_log.csv` に追記します。

## 週1回見ること
| 見る数字 | 計算 | 目安と対策 |
|---|---|---|
| 購入率 | 販売数 ÷ 記事PV | 1%未満 → 無料部分・タイトルを直す |
| 記事への流入 | 記事PV ÷ Threads表示数 | 低い → 固定ポストと誘導文を直す |
| 型ごとの反応 | 投稿の型別に、いいね・返信の平均 | 強い型を増やし、弱い型は切り口を変える |
| 月の着地見込み | 今月の手取り ÷ 経過日数 × 月の日数 | 10万円に届かない差を「あと何部」で出す |

## 次の商品への反映
- 返信で多かった質問 → 次の記事のテーマ候補
- 売れた後にもらった感想 → `references.md`（成功例）と `knowledge.md`（実績）に追記
- レビュー10件 → 2,980円に値上げ
