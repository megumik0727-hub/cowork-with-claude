# ⑥ Threads：固定ポスト＋集客投稿30本

## 運用ルール
- 1日1〜2投稿。**5つの型を順番に回す**（同じ型を連続させない）。
- 投稿本文にnoteのリンクは貼らない。**「固定ポストに置いてます」でプロフィールへ誘導**。
- 返信（コメント）には必ず返す。質問は次の投稿ネタにする。
- 数字は実際のものだけ。`【要記入】` はオーナーの体験で埋める。
- 固定：投稿の「…」→「プロフィールに固定」。機能が見当たらない場合は、プロフィール文にnoteのリンクを置く。

## プロンプト③：固定ポスト

### 設計（どこまで無料で、どこから有料につなぐか）
| パート | 役割 | 無料／有料 |
|---|---|---|
| 冒頭フック | 「質問してるから仕事が減らない」で手を止めさせる | 無料 |
| 悩みの言語化 | みさきさんの言葉で「それ私だ」と思わせる | 無料 |
| 解決策 | 「任せる＝5工程を渡す」「4つのファイル」という**考え方と名前**まで | 無料 |
| 具体的な手順・テンプレ | ファイルの中身、手順、プロンプト | **有料（note）** |
| 導線 | noteの無料部分を読むだけでも価値がある、と伝える | → noteへ |

### 本文（連投3つ）

**1/3**

それ、AIに「質問」してるだけだからかもしれません。

質問すると答えは返ってくる。
でもコピペして、自分の仕事に合わせて直すのは結局自分。
次の日もまた同じ説明から始める。

私もずっとそうでした。

**2/3**
仕事は5つの工程に分けられます。
①調べる ②決める ③作る ④確認する ⑤直す

AIに質問しているとき、手伝ってもらっているのは③だけ。
残りの4つは全部自分。だから楽にならない。

・仕事のルール
・自分の知識
・お手本
・過去のダメ出し

エンジニアじゃなくても作れます。
中身と、1つ目の仕事を任せるまでの手順をnoteに全部まとめました。
無料部分だけでも「何から任せるか」はわかるように書いています。

## 集客投稿30本

### 1〜5（1週目）

**#1 共感型**
「AI使って効率化して」って言われても、
何から任せればいいかわからない。

プロンプトの本を買っても、うちの仕事には当てはまらない。
毎回同じ説明をするのも面倒。

これ、あなたのせいじゃないです。
AIに「質問」する使い方しか教わってないだけ。
「任せる」使い方は別物です。

**#2 数字強調型**
毎日の仕事、5工程に分けると
①調べる ②決める ③作る ④確認する ⑤直す

ChatGPTに質問しているとき、AIがやっているのは5つのうち1つだけ。
だから「使ってるのに楽にならない」。

5つまとめて任せる方法、固定ポストに置いてます。

**#3 逆説型**
AIを上手に使いたいなら、
プロンプトを工夫するのを一度やめてみてください。

毎回うまく質問するより、
仕事のルールを1回ファイルに書いておくほうが、ずっと楽です。

AIは「その場の質問」より「覚えているルール」で動くほうが安定します。

**#4 体験談型**
エンジニアじゃない私が、Claude Code を触ってみました。

黒い画面を想像してたけど、実際はスマホからでも話しかけて指示できた。
最初に任せたのは【要記入：最初に任せた仕事】。

いちばん効いたのは、ダメ出しを「反省ノート」ファイルに書かせたこと。
同じミスをしなくなります。

**#5 保存重視型**
【保存版】AIに任せていい仕事の見分け方

次の4つ全部に○なら任せてOK
□ 週1回以上やっている
□ 毎回ほぼ同じ手順
□ 材料がファイルで手元にある
□ 出来上がりを5分で確認できる

1つ目のおすすめは議事録です。

### 6〜10（2週目）

**#6 共感型**
時短勤務なのに、仕事を持ち帰ってしまう日。
子どもが寝たあとにPCを開く日。

「時短だから仕方ないよね」って言われると、悔しい。

定型業務をAIに任せるのは、サボるためじゃなくて
自分にしかできない仕事と、家族との時間を取り戻すためだと思ってます。

**#7 数字強調型**
AIに仕事を覚えさせるのに必要なファイルは4つだけ。

1. 仕事のルール
2. 自分の知識（用語・取引先）
3. お手本（過去の良い成果物）
4. ダメ出しの記録

最初は各5行でOK。
中身のテンプレは固定ポストのnoteに載せてます。

**#8 逆説型**
AIの出来上がりがイマイチなとき、
自分で直すのはやめたほうがいいです。

自分で直すと、AIは何も学ばない。
「ここがダメ、次からこうして」と言葉で伝えて、記録させる。

直す手間は同じでも、2回目から楽になります。

**#9 体験談型**
AIに仕事を任せて、最初にやらかしたこと。

【要記入：失敗談。例「いきなり大きな資料を任せて、全部作り直しになった」】

学んだのは、「小さく・型がある仕事」から始めること。
いきなり全部任せるとうまくいかないです。

**#10 保存重視型**
【保存版】AIへの指示を変えるだけで精度が上がる言い方

✕ 長くしないで → ○ 3行以内で
✕ いい感じに → ○ このお手本と同じ形式で
✕ ちゃんと確認して → ○ わからない所は【要確認】と書いて
✕ 前にも言ったけど → ○ 反省ノートに追記して

### 11〜15（3週目）

**#11 共感型**
「AIってエンジニアのものでしょ」
私もそう思ってました。

でも今のAIは、パソコンのファイルを読んで、作って、保存までしてくれる。
必要なのはプログラミングじゃなくて、
「自分の仕事を言葉で説明する力」でした。

それ、事務の人がいちばん得意なやつです。

**#12 数字強調型**
事務職がAIに任せられる仕事、ざっと30個あります。

議事録／メール返信／社内通知／資料の要約／Excel集計／請求書の突き合わせ／週報／マニュアル化／比較表／研修資料のたたき台…

職種別の30リストはnoteにまとめてます。

**#13 逆説型**
AI活用がうまい人ほど、AIを信用していません。

だから最後の確認は必ず自分でやるし、
わからない所は「推測せずに【要確認】と書いて」とルールにしている。

任せるのは「下書き」まで。
それでも仕事は半分以上減ります。

**#14 体験談型**
CLAUDE.md というファイルを初めて作った日のこと。

「仕事のルールを書いておくと、AIが毎回読んでくれる」
これを知ったとき、正直ずっと損してたと思いました。

【要記入：初めて作ったときに書いたルール・感想】

**#15 保存重視型**
【保存版】議事録をAIに任せる5ステップ

1. 専用フォルダを作る
2. 過去のいちばん良い議事録を「お手本」として入れる
3. 社内の略語・名前の書き方を5行メモ
4. 「このメモから議事録を作って保存して」と頼む
5. ダメ出しを記録させる（3〜5回で安定）

### 16〜20（4週目）

**#16 共感型**
AIに毎回、
「うちの会社ではこういう書き方で…」
「◯◯さんは部長で…」

それ、1回ファイルに書けば二度と言わなくていいです。

**#17 数字強調型**

1回目：形式がズレる
2回目：抜けがある

**#18 逆説型**

「AIに仕事を任せられる人」と「任せられない人」の差が広がってます。

差がつくのはスキルじゃなくて、
自分の仕事を手順とルールに分けて説明できるかどうか。

**#19 体験談型**
AIに任せるようになって、いちばん変わったこと。

【要記入：例「帰りの電車で、明日の段取りを考えなくなった」など、時間や気持ちの変化】

仕事が減ったというより、
頭の中の「あれやらなきゃ」が減った感覚です。

**#20 保存重視型**

「このメールへの返信を3案作って。
丁寧／簡潔／断る場合。

3案もらって選ぶだけ。
ゼロから書くより、ずっと早いです。

### 26〜30（6週目）

**#26 共感型**
「AIに任せたら、自分の仕事がなくなるのでは」
って不安、ありますよね。

でも実際に任せてみると、
残るのは「決めること」と「人と話すこと」。
むしろ、自分にしかできない仕事がはっきりします。

**#27 数字強調型**
AIに任せる仕事の選び方、4つのチェックだけ。

□ 繰り返し
□ 型がある
□ 材料がある
□ 確認できる

4つ○→今日任せる
3つ○→来週
2つ以下→まだ自分で

チェックシートはnoteの特典に入れてます。

**#28 逆説型**
AIを使いこなすのに、最新情報を追いかける必要はないです。

新しいツールが出るたびに乗り換えるより、
1つのツールに自分の仕事のルールを覚えさせるほうが、ずっと成果が出る。

積み上がるのは、ツールじゃなくてルールのほうです。

**#29 体験談型**
noteに書いた「AIに仕事を任せる手順」、
読んでくれた方から【要記入：実際にもらった感想】と言ってもらえました。

同じように「質問はしてるけど任せられてない」人に届いたらうれしいです。

**#30 保存重視型**
【保存版】今日からできる「AIに任せる」最初の一歩

1. フォルダを1つ作る
2. 「仕事のルール」ファイルに3行書く
3. 過去の良い成果物を1つ入れる
4. 議事録を1本任せる
5. ダメ出しを記録させる

全手順とテンプレは固定ポストから。
