| 10 | 中学受験・高校受験の「親の伴走記録」 | 1,480〜2,980円 | 毎年新しい読者が入れ替わる。体験記が長く売れる |

## 選んだジャンル（暫定）

**#1 ＋ #9 の組み合わせ：「非エンジニア会社員のための Claude 丸投げ業務術」**

理由：
- 需要：公式データで「AI活用」が急成長。実用ノウハウ系は平均1,842円で単価が高い。
- 競合：「Claudeで副業」は多いが、**本業の仕事を任せる**切り口は少ない。
- 書き手の強み：オーナー自身がいま非エンジニアとして Claude Code を使い始めている。
  **この取り組み自体が「実録」になる**（売れる型の1位）。
- 広がり：同じ読者に、テンプレ集・メンバーシップ・職業別編（#2, #3）を追加で売れる。

> ⚠ `knowledge.md` の職種・経験が埋まったら見直します。
> 医療・教育・介護などの現場経験があれば #2 や #3 のほうが強く、競合も少ないです。

## プロンプト②：いちばん悩みが深そうな1人

**名前（仮）：佐藤 みさき さん／36歳**

- **状況**：従業員80人の会社で総務と経理を兼任。小学1年の子どもがいて時短勤務（9時〜16時）。
  夫も会社員で、お迎えと夕食はほぼみさきさん担当。
- **毎日の仕事**：議事録、社内通知の文面、請求書のチェック、Excelの集計、問い合わせメールの返信。
  「誰がやっても同じ仕事」に1日の半分を取られている。
- **AIとの距離**：ChatGPTは無料版を何度か使った。でも「質問すると答えは返ってくるけど、
  結局コピペして直すのは自分」で、仕事が楽になった実感はない。
  Claude Code は名前だけ知っているが「エンジニア向けでしょ」と思っている。
- **いちばん深い悩み**：時短なので残業できない。仕事を持ち帰り、子どもが寝たあとに
  PCを開く日が週2〜3回ある。評価面談で「時短だから仕方ないよね」と言われたのが悔しい。
- **本人の言葉づかい**：
  - 「AI使えって言われても、何から任せればいいかわからない」
  - 「プロンプトの本を買ったけど、うちの仕事には当てはまらなかった」
  - 「毎回同じ説明をAIにするのが面倒」
  - 「エンジニアじゃないし、黒い画面は怖い」
  - 「定時で帰って、ちゃんと子どもと夕飯を食べたい」
- **買う決め手**：自分と同じ非エンジニアの実例。明日そのまま使えるテンプレ。
  「1つ目の仕事を任せるまで」が迷わずできること。
- **払える金額**：ランチ2回分（2,000円前後）なら迷わない。3,000円を超えると「本当に使えるか」レビューを見たい。
